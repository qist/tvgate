## 二、商店更新说明 · 标准版（≤ 800 字符）

```
【v3.3.1 更新内容】
1. 直播断线自动续播 — 直播源定时断开连接不再让画面"停住"：自动接续时间轴继续播，直播延迟
   保持在几秒内（以前会越拖越长）；换线路/换源后同样直接续播
2. 换线路更可靠 — 解析出的播放地址会定期刷新，失效立即重新解析，不再"播几秒断一次、
   一直重连同一条坏地址"
3. 开启缓存后新观众不再黑屏 — 打开 TS 缓存（多观众共享一路流）时，后加入的观众拿不到
   SPS/PPS、AAC 配置会黑屏花屏，现已按完整数据包解析并正确下发
4. 手机端控制条移到画面外 — 原生解码时播放/暂停、音量、换线路放到画面下方（被浏览器
   接管画面的机型也能看到和点击）；换线路改为点击弹出的置顶菜单，选中即收起
5. 修复与优化 — 切台后画面全黑需点一下才恢复；小米等浏览器无媒体徽标/部分台黑屏；
   起播更快（不再为判断播放列表白等几秒）；新增 ?dbg=1 播放诊断浮层

提示：本版本同时更新了内嵌服务端，建议使用同一版本的 App 与 Web 管理后台。
```

## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.3.1（2026-09-19）

### 本次亮点
- 断线续播：直播源定时断开时，画面不再"停在断开那一刻"；重连自动接续时间轴继续播，
  直播延迟保持在几秒内
- 手机端体验：原生播放时播放/音量/换线路移到画面下方（被浏览器接管画面的机型也能用），
  换线路改为置顶弹出菜单、选中即收起

### 修复
- 直播断线重连后画面停住不动、延迟越拖越长
- 解析出的播放地址过期后反复重连（上游看到持续重连，可能触发风控）
- 开启 TS 缓存时后加入的观众黑屏/花屏（拿不到编码参数）
- 切台后画面全黑、需要点一下才恢复
- 小米等浏览器"没有媒体徽标 / 部分台黑屏"

### 优化
- 起播更快：不再为判断播放列表白等几秒，也少拉一路数据
- 新增 ?dbg=1 播放诊断浮层（报障时使用）

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 本次 App 侧无独立代码改动，随内嵌服务端同步发版
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```

## 五、敏感权限说明（如商店审核问询时使用）

| 权限 | 用途 |
|---|---|
| 网络访问 / 前台服务 | 在本机启动网关与播放服务，供局域网内设备访问 |
