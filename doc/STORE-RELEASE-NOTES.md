## 二、商店更新说明 · 标准版（≤ 800 字符）

```
【v3.4.1 更新内容】
1. 修复画面定格 — 多线路频道从 HLS 线路切到 MP4 线路后，画面会停在切走前那一帧，
   必须刷新页面才恢复；现在切换后直接出图
2. 换线路不串解码 — 换台 / 换线路时作废旧线路的容器探测结论，避免 TS/HLS 流被误锁在
   原生解码，画质徽标与追边表现与换台前一致
3. 老内核兼容 — 不支持 module worker 的内核自动退到兼容模式；本地存储 / 系统主题接口
   缺失时不再中断首帧渲染；资源加载失败会直接提示，便于排查「标题正常、页面全白」
4. 上游失败熔断 — 同一条坏地址连续失败后进入冷却，不再反复穿透上游；恢复后自动放行
5. m3u8 改写归一 — 内嵌密钥 / 初始化段地址统一走代理与域名映射，TS 分片恢复定长

提示：本版本同时更新了内嵌服务端，建议使用同一版本的 App 与 Web 管理后台。
```

## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.4.1（2026-10-18）

### 本次亮点
- 修复多线路频道从 HLS 切到 MP4 后画面定格、必须刷新的问题
- 换台 / 换线路不再沿用上一台的解码方式
- 老旧电视盒子内核兼容改进，播放链路不再静默黑屏

### 功能与改进
- HLS → MP4 切换：播放器换用原生解码时同步撤掉旧的 H5 渲染画面，切到 MP4 直接出图
- 换线路：作废上一台的首段容器探测结论，避免把 TS/HLS 流误锁在原生后端；
  探测结果不再覆盖设备能力判定，X5 等内核不会整条链路静默不启动
- 老内核兼容：module worker 创建失败自动退到 classic；本地存储被禁用 / 系统主题接口
  缺失不再中断首帧渲染；静态资源加载失败直接上屏提示
- 上游失败熔断（内嵌服务端）：同一地址连续失败后冷却，冷却内直接返回 502 并带
  Retry-After，不再反复穿透上游、不再刷日志；冷却逐次翻倍至 5 分钟
- m3u8 改写归一（内嵌服务端）：列表统一按 200 全量返回，内嵌 URI 走代理与域名映射，
  TS 分片恢复定长
- 后台可用性：鉴权状态请求加 12 秒超时与「重试」入口，不再无限「加载中…」

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 内嵌服务端同步至 v3.4.1（versionCode 6，可覆盖安装升级）
- 建议 App 与 Web 管理后台使用同一版本
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```
