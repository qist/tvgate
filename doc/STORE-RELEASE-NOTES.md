## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.3.6（2026-09-27）

### 本次亮点
- 修掉两类"只在特定设备上出现"的问题：旧设备的软解音频全程无声，
  以及播放页遥控器完全无反应

### 修复
- 旧设备（系统 WebView 较旧，典型是安卓 8 电视盒子）播放 MP2 / AC-3 /
  E-AC-3 音轨的频道时有画面没声音：本地音频解码模块用到了较新的
  WebAssembly 指令，旧系统无法加载该模块；现降级为通用指令集，
  实测新旧产物解码输出逐样本一致，音质不受影响
- 播放页遥控器完全无反应（方向键、OK、数字键均无效，鼠标/空鼠正常）：
  按键此前被系统层消费却未送达页面，现改为兜底注入并回读确认，
  桥未就绪时不再吞掉按键
- 后台入口页面不再被缓存，升级后不会再看到旧界面

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 内嵌服务端同步至 v3.3.6；建议 App 与 Web 管理后台使用同一版本
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```
