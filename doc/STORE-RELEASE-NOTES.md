## 二、商店更新说明 · 标准版（≤ 800 字符）

```
【v3.4.6 更新内容】
1. 动态代理池 — 代理组支持按「网关 + 端口段」展开候选出口，后台定时探测、按响应时间
   排序并自动故障切换；支持与固定代理节点混用；后台「代理组」页面可编辑池参数，并
   展示探测成功的端口、协议、延迟与状态
2. 探测 UA 可配置 — 新增组级 probe_ua，只影响探测/测速；修复只认 QTP / okhttp 等特定
   UA 的源站探测一直 403、节点被误判并进入冷却的问题；播放仍按频道配置透传
3. 探测逻辑统一 — 动态池与选路共用同一套直播检测（HTTP / RTSP），支持单轮重试；异步
   结果判定与主流程一致，减少状态码误读
4. 播放修复 — H5 播放器解析型源（php 302）的原始入口不再沿用分片代理出口，302 目标仍
   走代理；避免入口不可达时把代理节点打成连续失败
5. App 前端无改动 — 本次仅随内嵌服务端重新打包，覆盖安装即可升级
```

## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.4.6（2026-11-21）

### 本次亮点
- 内嵌服务端同步至 v3.4.6：动态代理池、探测 UA 配置、H5 播放器解析入口修复
- App 前端无改动，覆盖安装即可升级

### 功能与改进
- 动态代理池：代理组新增 pool，按「网关 + 端口段」展开候选节点，后台按 probe_interval
  定时探测并排序，失败节点进入冷却后仍会在下一轮重测；probe_retries 支持单轮内立即重试
- 后台可视化：代理组页面可新增/编辑池，展示探测成功的端口、协议、延迟、HTTP 状态与
  失败次数；页面空闲时自动刷新
- 探测 UA：组级 probe_ua → 全局 player.ua → 不发送，只影响探测/测速；播放请求仍按频道
  ua= 或 player.ua 透传
- 探测与选路统一：动态池复用 lb 的直播检测（HTTP Range / RTSP），异步消费判定与主循环
  一致，206 分片响应计为成功；失败时清理过期状态码，避免日志误读
- 播放修复：H5 解析型源的原始入口不再强制沿用分片代理出口，302 指向的播放地址仍交给
  代理组拉取，避免入口地址不可达时把节点测成连续失败

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 内嵌服务端同步至 v3.4.6（versionCode 14，可覆盖安装升级）
- 建议 App 与 Web 管理后台使用同一版本
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```

## 五、敏感权限说明（如商店审核问询时使用）

| 权限 | 用途 |

| 网络访问 / 前台服务 | 在本机启动网关与播放服务，供局域网内设备访问 |
| 开机自启 | 设备（机顶盒/电视）重启后自动恢复服务，达到"开机即用" |
