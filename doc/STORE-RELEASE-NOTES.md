## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.3.7（2026-10-02）

### 本次亮点
- 修掉部分 PHP 直播源脚本在本机执行失败（403 / 报错 / 解密失败）
- 修掉播放页弹出窗口或切后台后状态栏常驻、把画面顶出屏幕的问题

### 修复
- PHP 源脚本本机执行修复（phpgo 解释器）：
  - 函数参数「类型提示 + 引用」解析失败（array &$id）→ 报错「函数参数须为变量」
  - 字符串下标赋值语义错误（$s[$i] = 'x'）→ 整串数据损坏成 "Array"
  - openssl_encrypt GCM 模式未写回认证标签 → 服务端 403 或解密失败
  - PATH_INFO 路由 403（/ysptp.php/cctv1.m3u8 等）→ 找不到文件直接拒绝
  - 现已全部修复，4gtv.php / ysptp.php 等常见 PHP 源可正常请求
- 播放页状态栏沉浸修复：
  - 弹窗（权限/更新）或切到后台后再回来，状态栏常驻不消失，H5 安全区
    持续存在导致画面和控制条被顶出屏幕
  - Android 11+ 声明系统栏行为为「瞬态」（短暂悬浮自动收回）；焦点恢复时
    主动重新进入沉浸，状态栏只在需要时短暂出现
- /debug/pprof 安全收敛：常规构建不再包含 pprof 端点，调试时加编译标签即可

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 内嵌服务端同步至 v3.3.7；建议 App 与 Web 管理后台使用同一版本
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```

## 五、敏感权限说明（如商店审核问询时使用）

| 权限 | 用途 |
|---|---|
| 网络访问 / 前台服务 | 在本机启动网关与播放服务，供局域网内设备访问 |
| 开机自启 | 设备（机顶盒/电视）重启后自动恢复服务，达到"开机即用" |
| 通知 | 前台服务常驻通知，展示局域网访问地址与停止服务按钮 |

> 说明：服务仅在本机与局域网内运行，不采集、不上传用户数据。
