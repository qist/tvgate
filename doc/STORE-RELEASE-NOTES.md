## 二、商店更新说明 · 标准版（≤ 800 字符）

```
【v3.4.7 更新内容】
1. 代理组状态显示修复 — 更新或重启后，节点在测速结果返回前只有一个开始时间，之前后台
   会把它显示成绿色「在线」而延迟为「—」；现在统一显示「未测」，不再给出错误结论
2. 判定更严格 — 成功以延迟/状态码为准，失败以失败次数为准；只有开始时间、三项均为 0
   时按未测处理；静态节点与动态端口池节点使用同一套判定
3. 统计零值处理 — 从未测速或没有冷却时，后端直接返回空值，不再输出 0001-01-01 这类
   占位时间，避免前端误判
4. App 前端无改动 — 本次仅随内嵌服务端重新打包，覆盖安装即可升级；其余功能与 v3.4.6 一致
```

## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.4.7（2026-11-21）

### 本次亮点
- 内嵌服务端同步至 v3.4.7：修复代理组未测速节点误显示「在线」
- App 前端无改动，覆盖安装即可升级

### 问题与修复
- 现象：更新或重启后，代理组里的节点全部显示绿色「在线」，但延迟为「—」、连续失败为 0
- 原因：测速开始时会先写入开始时间以避免并发重复测速；请求成功标记也会把存活状态置为
  true，但不写延迟和状态码。旧版前端只判断开始时间是否非空，于是把「测速中」当成「在线」
- 修复：只有延迟、状态码、失败次数任一非 0 时才判定为已测；只有开始时间时显示「未测」
- 零值时间不再序列化成 0001-01-01，直接返回空值，避免前端误判

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 内嵌服务端同步至 v3.4.7（versionCode 15，可覆盖安装升级）
- 功能与配置行为与 v3.4.6 一致，可直接覆盖升级
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```
