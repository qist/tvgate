## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.3.4（2026-09-25）

### 本次亮点
- EPG 节目单终于"对得上台"：带 4K/高清 等画质后缀的频道名此前原样发给
  外源节目单服务，被模糊匹配到无关频道（CCTV1-4K 实测显示 CCTV14 少儿
  频道的节目单）；现在查询前先剥画质后缀（CCTV1-4K→CCTV1），剥完无结果
  再回落原名，带后缀频道全部恢复正常
- 打开更快：台标死链检测从启动路径移到后台执行，频道列表不再等它，
  APK 打开即出列表；检测结论落盘持久化，重启后不再重复探测、死台标
  不再"复活"闪 404

### 修复
- 代理组修改规则/域名后，旧的分流映射残留导致请求继续走改前规则
  （组内域名删光或挪组时缓存清不掉、整组删除无人清理）；现在配置变更
  按组名全量清理，改完立即生效
- EPG 频道错配（见亮点）
- 配置热更新路径一处长期存在的数据竞争（-race 检出）

### 优化
- EPG 节目单每天凌晨 0 点自动失效重拉，跨天不再显示前一天内容
- 管理后台代理组页面每组新增「清理缓存」按钮：一键清空该组访问缓存并
  重置测速统计，下次请求强制重新测速选节点
- 依赖更新：gortsplib/v5 5.6.6

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 本次 App 侧无独立代码改动，随内嵌服务端同步发版
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```
