## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.2.2（2026-09-16）

### 本次亮点
- 网络切换/断流自愈：从 WiFi 切到 4G/5G、隧道/电梯等真实断网后，播放自动重连恢复，
  不再出现"永久转圈""只剩画面没有声音""音画再也对不上"
- 播放更稳：修复偶发的"声音卡顿一下"；长时间播放音画持续同步；异常时自动恢复播放
- 播放期间屏幕常亮，支持后台持续播放（熄屏场景由系统策略决定）

### 修复
- 网络切换后音画不同步 / 声音消失 / 播放卡死
- 偶发声音卡顿、播放中丢失少量音频
- 缓冲耗尽后无法自行恢复（现在会自动按直播位置重建）
- 主题预置偶发不生效
- 返回键偶尔无法退出播放页
- 在线更新弹窗偶发重复或不显示

### 优化
- 直播转发/播放缓冲策略优化，弱网与分片稀疏时卡顿明显减少
- 频道节目单（EPG）匹配更准，支持压缩格式源与主源失效自动回退
- 软解音频新增"单声道合成"选项（分离声道源在手机上两边声音都能听到）
- 诊断日志更完整，便于反馈问题定位

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```

## 五、敏感权限说明（如商店审核问询时使用）

| 权限 | 用途 |
|---|---|
| 网络访问 / 前台服务 | 在本机启动网关与播放服务，供局域网内设备访问 |
| 开机自启 | 设备（机顶盒/电视）重启后自动恢复服务，达到"开机即用" |
| 通知 | 前台服务常驻通知，展示局域网访问地址与停止服务按钮 |

> 说明：服务仅在本机与局域网内运行，不采集、不上传用户数据。
> 使用播放能力时，请确保内容来源的合法授权。
