## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.3.0（2026-09-19）

### 本次亮点
- 兼容性修复：部分直播源（江苏移动/魔百盒类 CDN）此前"一直加载中"打不开，现已修复；
  切台不再卡顿、不再持续丢帧
- 整点断流治理：整点跨小时分片异常不再"卡 30 秒"（缓冲缺口瞬间跳过），断档后声音
  自动回来
- 频道与节目单：EPG 多来源合并与主源回退；分组内同名频道支持多线路切换与自动故障转移
- 界面焕新：频道列表（首字徽章 / LIVE 标识 / 分组计数 / 搜索号位）与播放页
  （媒体信息徽标、界面风格）

### 修复
- 部分源视频轨拿不到参数集/关键帧导致永不开播（一直加载中）
- 切台后反复缓冲、持续丢帧
- 整点时段长时间停拉与跳片
- 多伴音流（6 音频 + 1 视频）被拒收、AC-3 主轨丢失、媒体徽标被备轨覆盖
- 广播/纯音频频道无声与黑屏
- 播放服务重启窗口内弹错误提示、播放 worker 崩溃后不重建

### 优化
- 起播与列表轮询更省流量（起播只请求一次播放列表、空闲轮询自适应节流）
- 缓冲见底时更密集地补片，临界缓冲更稳
- 后台示例与测试夹具脱敏（不再包含真实脚本名/内网 IP）

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 本次 App 侧无独立代码改动，随内嵌服务端同步发版
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```

## 五、敏感权限说明（如商店审核问询时使用）

| 权限 | 用途 |
|---|---|
| 网络访问 / 前台服务 | 在本机启动网关与播放服务，供局域网内设备访问 |
| 开机自启 | 设备（机顶盒/电视）重启后自动恢复服务，达到"开机即用" |
| 通知 | 前台服务常驻通知，展示局域网访问地址与停止服务按钮 |

> 说明：服务仅在本机与局域网内运行，不采集、不上传用户数据。
> 使用播放能力时，请确保内容来源的合法授权。
