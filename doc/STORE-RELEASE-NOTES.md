## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.3.9（2026-10-05）

### 本次亮点
- 修复开启全局授权后播放页「能打开但一片空白」：/pp 页面本体纳入令牌校验
- 修复开启授权后没有画面：m3u8 分片与回看地址在服务端签发时自带授权令牌
- 支持自定义令牌参数名，前后端按同一份配置读取，老的 my_token 链接继续可用

### 修复与改进
- /pp 独立播放页纳入全局授权：
  - 现象：开启 global_auth 后接口早已 403，但页面裸放行，于是「能打开但一片空白」
  - 修复：/pp 与深链统一走令牌校验，失败返回 403 并记日志
  - 未启用授权时直接透传，行为与从前完全一致；静态资源不受影响
- m3u8 与回看地址自带授权：
  - 分片行、EXT-X-KEY / EXT-X-MAP / EXT-X-MEDIA 内嵌地址、回看 play 地址统一补令牌
  - 原因：hls.js 与第三方播放器按播放列表原样请求，不会像页面那样补令牌，不签就 403
  - 效果：歌单能拉到就能出画面，回看地址复制即可播
- 令牌参数名前后端对齐：
  - 播放页注入 meta 指明参数名（取自 global_auth.token_param_name）
  - 服务端按配置名取值、取不到回落 my_token，两个名字互为兼容
  - 配置自定义参数名（如 ouyyt）的部署不再全部 403，老分享链接继续可用
- 修 token_param_name 未配置时的全量 403：参数名为空曾导致所有播放请求被拒；
  PHP 采集入口同时剥离配置名与默认名，避免令牌进入脚本 $_GET
- 后台外链自动补签：分享外链、EPG 接口、player 入口与 /pp?live= 预览、回放地址
  按配置自动追加令牌，复制即用；未启用授权或没有静态令牌时原样返回
- 前端对服务端已签名地址跳过补签，不再产生重复的同名令牌参数

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 内嵌服务端同步至 v3.3.9（versionCode 4，可覆盖安装升级）
- 建议 App 与 Web 管理后台使用同一版本
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```
