## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.4.10（2026-11-22）

### 本次亮点
- 内嵌服务端同步至 v3.4.10：后台列表删空可保存、H5 播放页更流畅、删除文件需确认
- 完成一轮依赖安全升级（npm audit 归零）
- App 前端无改动，覆盖安装即可升级

### 问题与修复
- 现象一：定时任务删到最后一个后「保存全部配置」按钮消失；仓库同步删掉最后一个仓库
  后被「至少填写一个」拦住；定时任务/代理组删掉几秒后又被轮询拉回来
  修复：允许保存空列表（tasks: [] / sync: []），有未保存改动时暂停轮询，保存后复位
- 现象二：部分 App WebView 忽略 window.confirm，点删除代码文件直接落盘
  修复：改为应用内确认弹窗，确认后才删除；目录明确提示连同全部内容
- 现象三：播放页在低端机上滚动节目单/频道列表发涩，切台时偶有掉帧
  修复：播放器壳 memo 化、节目单改分钟级刷新、当前节目只算可见频道、
        手机端去掉节目单吸顶头的逐帧模糊

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 内嵌服务端同步至 v3.4.10（versionCode 18，可覆盖安装升级）
- 配置格式向后兼容，旧 config.yaml 可直接使用
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```
