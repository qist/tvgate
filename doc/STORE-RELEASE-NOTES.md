## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.3.3（2026-09-24）

### 本次亮点
- iPhone Safari 播放一直转圈修复：iOS 17+ 走系统托管媒体源（ManagedMediaSource），
  其激活要求在挂源前于 video 元素上声明不使用投屏，此前声明位置无效导致画面
  就绪事件被抑制、播放管线永不启动；已按规范修复，并优化首包数据补发与就绪
  看门狗，事件时序异常时也能自动恢复
- iOS 15 白屏修复：旧版 Safari 缺少屏幕方向接口导致打开播放页整页崩溃，
  已做兼容处理

### 修复
- iPhone Safari（iOS 17+）播放一直转圈、无法出画
- iOS 15 等旧设备打开播放页整页白屏
- 换台时的良性加载中断被误报为播放失败，可能触发不必要的自动切线路

### 优化
- 原生播放失败提示更明确：显示具体错误代码与原因；解码/格式类失败会提示
  常见原因（如 MP2/MP3/AC-3 音轨不被系统原生播放支持，属设备系统级限制，
  安卓与 iOS 17+ 走引擎软解路径可正常观看）
- 启动错误上屏：脚本异常、资源加载失败在页面底部红条直接显示，白屏 6 秒
  兜底提示，旧 WebView / 低版本系统排障不再无声无息
- 诊断日志收口：播放器控制台默认零输出；需要排查时地址加 ?dbg=1 或控制台
  执行 __tvdbg() 一键开启（主线程与解码工作线程全覆盖）；真正的错误日志
  不受开关影响始终显示
- 播放诊断浮层新增媒体源状态行（MS源），一眼确认系统托管源是否激活

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 本次 App 侧无独立代码改动，随内嵌服务端同步发版
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```
