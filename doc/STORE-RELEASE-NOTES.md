## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.3.5（2026-09-26）

### 本次亮点
- 手机管理后台终于排得下：此前在手机上打开后台，多处页面内容溢出屏幕、
  按钮被裁到看不见（编辑内容类页面尤其明显）；现在窄屏自动换行、操作按钮
  独立成行，备份列表的文件名也能完整看到是哪一个备份

### 修复
- 管理后台窄屏横向溢出：YAML 编辑器「保存」、配置备份「批量删除」、备份中心、
  域名映射的页头按钮被裁；配置备份文件名被挤成一个「config.yaml…」
- 编辑文件页工具栏撑破页面，导致整页可横向滑动、末尾按钮不可见
- 任务页点「添加」报 JS 错误（Cannot read properties of undefined）导致页面崩溃

### 优化
- 后台入口页面不再被缓存，升级后不会再拿着旧页面引用已不存在的旧资源
- 卡片组件补最小宽度约束，避免内部宽表格把整页撑开

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 本次 App 侧无独立代码改动，随内嵌服务端同步发版
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```

## 五、敏感权限说明（如商店审核问询时使用）

| 权限 | 用途 |
|---|---|
| 网络访问 / 前台服务 | 在本机启动网关与播放服务，供局域网内设备访问 |
| 开机自启 | 设备（机顶盒/电视）重启后自动恢复服务，达到"开机即用" |
| 通知 | 前台服务常驻通知，展示局域网访问地址与停止服务按钮 |

> 说明：服务仅在本机与局域网内运行，不采集、不上传用户数据。
> 使用播放能力时，请确保内容来源的合法授权。
