## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.4.0（2026-10-12）

### 本次亮点
- 新增 MKV（Matroska）直链播放，seek 与回看可用
- 修复渐进式 MP4 流黑屏：自动改走原生解码播放
- 播放失败时不再卡住：错误面板可直接唤出频道列表换台

### 功能与改进
- MKV 直链支持：新增 EBML 探测与 Matroska 解复用，4K HEVC + E-AC-3 可直接播放，
  seek 走 Range 重载并上报容器时长
- 渐进式 MP4（ISO BMFF）：转封装管线首块识别 ftyp/styp 并上报 FormatUnsupported，
  播放器自动改用原生后端重灌；起播前先探首段容器形态，命中 MP4 直接选原生后端
- 播放失败不再卡死：错误面板不再阻断画面点击，新增「打开频道列表」按钮
- 本地推流状态：后台「运行状态」按最近 15 秒是否有流数据判定「正在推流」
- 新建推流补「推流名称」输入框，支持改名且防同名覆盖
- 安全收口：备份删除接口强制 POST / 需提权 / 只允许删 .backup. 文件

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 内嵌服务端同步至 v3.4.0（versionCode 5，可覆盖安装升级）
- 建议 App 与 Web 管理后台使用同一版本
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```

## 五、敏感权限说明（如商店审核问询时使用）

| 权限 | 用途 |
|---|---|
| 网络访问 / 前台服务 | 在本机启动网关与播放服务，供局域网内设备访问 |
| 开机自启 | 设备（机顶盒/电视）重启后自动恢复服务，达到"开机即用" |
| 通知 | 前台服务常驻通知，展示局域网访问地址与停止服务按钮 |

> 说明：服务仅在本机与局域网内运行，不采集、不上传用户数据。
> 使用播放能力时，请确保内容来源的合法授权。
