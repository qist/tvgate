## 三、商店更新说明 · 详细版（无字数限制，用于官网 / 论坛 / Release Notes）

```
## v3.3.2（2026-09-21）

### 本次亮点
- 部分频道打不开修复：个别旧 CDN 仅支持旧式加密握手（TLS 1.2 + 静态 RSA），新版
  客户端握手被直接拒绝；已恢复兼容，一行覆盖全部出站链路，正常站点不受影响
- 台标自动清理：失效台标直接显示首字徽章，频道列表更快更干净

### 修复
- 个别旧 CDN 握手被拒（remote error: tls: handshake failure）导致频道一直打不开
- 手机端原生播放时音量滑杆向上弹出、被播放画布拦截无法触控 → 改为向下弹出
  （与换线路菜单一致），桌面浮层模式不变

### 优化
- 台标死链自动清理：订阅刷新时后台轻量并发探测（限流 + 时间预算，不拖重载），
  确认失效的置空改用首字徽章；防盗链等不确定结果自动保留、防误杀；结论缓存
  （命中 24 小时 / 缺失 2 小时），日常刷新零探测开销
- 本地台标目录响应补缓存头（4 小时 + 条件校验），与外部图床行为一致

### 说明
- 支持 Android 5.0 及以上；arm64-v8a / armeabi-v7a / x86_64
- 本次 App 侧无独立代码改动，随内嵌服务端同步发版
- 开发侧：TVBox 兼容的全平台客户端设计基准（TVFusion）已入库，
  见 doc/tvbox-universal-client-design.md
- 完整改动见 doc/CHANGELOG.md（Android 与 服务端 两段）
```

## 五、敏感权限说明（如商店审核问询时使用）

| 权限 | 用途 |
|---|---|
| 网络访问 / 前台服务 | 在本机启动网关与播放服务，供局域网内设备访问 |
| 开机自启 | 设备（机顶盒/电视）重启后自动恢复服务，达到"开机即用" |
| 通知 | 前台服务常驻通知，展示局域网访问地址与停止服务按钮 |

> 说明：服务仅在本机与局域网内运行，不采集、不上传用户数据。
> 使用播放能力时，请确保内容来源的合法授权。
