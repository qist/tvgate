## 二、GitHub Releases 正文 · 精简版

```
### v3.3.0 更新内容
1. 修复部分 IPTV 源"一直加载中"打不开 — 江苏移动系（魔百盒 CDN）在 GOP 边界注入的访问单元不携带时间戳，此前被整包丢弃，导致视频轨拿不到 SPS/PPS 与关键帧；切台卡顿与持续丢帧一并修复
2. 整点断流治理 — 跨小时分片目录自动纠偏、缓冲缺口瞬间跳过（"卡 30 秒"变"瞬间跳过"）、断档后"画面恢复但声音不回来"修复
3. 多音轨与声画分流 — 多伴音流不再被拒收、AC-3 主轨与媒体徽标正确、独立音轨直通、音频锚定视频基准做音画对齐
4. 广播/纯音频频道可用 — 支持裸 ADTS AAC 分片（广播频道不再无声），纯音频频道显示广播占位
5. EPG 与频道列表 — EPG 多来源合并与统一入口；组内同名频道聚合多线路，可手动换线路并自动故障转移；频道列表美化与播放页改版
6. 播放更省流量更稳 — 起播播放列表只请求一次、空闲轮询自适应节流；服务重启窗口内不再弹错误、worker 崩溃自动重建
7. 合规 — 播放引擎完成去 GPL 重写（clean-room 自研，MPL-2.0），依赖树无 GPL/LGPL 组件

完整改动见 doc/CHANGELOG.md（服务端条目 8 项、安卓条目 2 项）。升级：下载对应平台 zip 覆盖二进制后重启服务。
```

## 三、完整版（用于发布公告 / 论坛 / 通知）

```
## v3.3.0（2026-09-19）

相对 v3.2.2 共 58 个提交，服务端条目 8 项，重点如下。

### 一、播放器起播与切台（本版最大修复）
- 江苏移动系（mobaibox/Huawei CDN）频道"一直加载中"彻底修复：源在 GOP 边界注入
  [PPS][AUD][SPS][PPS][IDR] 访问单元且不携带 PTS/DTS（ISO 13818-1 中 PTS 为可选），
  旧逻辑整包丢弃 → 视频轨永远拿不到参数集与关键帧、轨无法发布
- 同批修掉视频轨晚于音频发布时的 init 顺序竞态（视频 SourceBuffer 永远建不出来）
  与视频成段未回关键帧边界导致的切台卡顿/反复缓冲
- 同类流（广场舞等）同步受益；广播/纯音频频道恢复有声（裸 ADTS AAC 分片 + 跨 PES 接帧）

### 二、整点断流与跳片治理
- 跨小时分片目录纠偏：整点分片 404 时回退上一小时目录，整点不再断流
- MSE 缓冲缺口跳过（gap skip）：把整点缺片的"卡 30 秒"变成"瞬间跳过"
- 软解 PCM 时间轴保留大跳变：修整点断档后"画面恢复、声音不回来"
- HLS 分片失效按批次刷新播放列表快速恢复（不再死啃旧分片）；上游抖动导致的长时间
  停拉与跳片修复；非解析型上游请求不再重试（消除整点分片的成倍重试日志）

### 三、起播性能、多音轨与稳定性
- 起播路径播放列表只请求一次（省一次完整往返）；HLS 空闲轮询按目标时长自适应节流
  （一个分片窗口只开一次）；缓冲见底时改回 1 秒密集问保护临界缓冲
- 多伴音流（6 音频 + 1 视频）多音轨撞 SourceBuffer 被拒收修复；AC-3 主轨丢失与
  媒体徽标被 MP2 备轨覆盖修复；独立音轨（声画分流）走 MSE 直通并锚定视频基准
- 切台旧音轨残留、无缝切台过渡期音量状态保护；源初始化零重试与服务重启窗口内的
  worker 崩溃重建修复（不再弹错误/立即断开）

### 四、EPG 与频道列表
- EPG 多来源合并与主源回退、多订阅源解析、统一入口（ch 认 tvg-id/频道名/key，
  date 可选）与对外 ch 查询；订阅/EPG 跟随重定向
- 组内同名频道聚合多线路：前端可手动换线路并自动故障转移
- 频道列表美化（首字徽章 / LIVE 标识 / 分组计数 / 搜索号位）、台标前置与自愈、
  打开侧边栏把在播频道定到列表正中、分组筛选跟随正在播放的频道；播放页与后台界面改版

### 五、其它修复与优化
- phpgo：PCRE 内核完整化（RE2 换 regexp2 回溯引擎，PHP 语义全对齐）
- 崩溃转储与标准库日志写入日志文件（不再依赖启动脚本的 2>&1）
- 全局配置先补默认值再发布，修掉热重载后进程被空指针带走
- 后台订阅源/定时任务示例与测试夹具脱敏（去除真实脚本名 / 内网 IP / 源站域名）

### 六、合规（本版重要变更）
- 播放引擎整体迁移为 ui/src/media-engine（解封装/软解/管线/wasm 重组，clean-room
  自研实现，MPL-2.0）；UI 外壳（播放页、管理界面组件、i18n、播放页入口脚本、样式表）
  完成 clean-room 重写；内部契约去同源化（/api/player/* v2）
- 新增 THIRD-PARTY-NOTICES 并在 README 标注许可分界；与 GPL 上游逐文件指纹复测：
  引擎 k=8 零成块重合、全量 k=6 仅余接口字段与常量字面量
- 依赖侧核查：Go（53 模块）与 npm 运行依赖无 GPL/LGPL/AGPL；FFmpeg WASM 仅 LGPL
  组件、独立资源分发且已声明源码获取途径

### 兼容性与升级
- 配置文件向后兼容：本版无破坏性配置变更，旧 config.yaml 可直接使用
- 二进制升级：下载对应平台 zip，覆盖原二进制后重启服务（systemd：systemctl restart tvgate）
- Docker 升级：docker pull juestnow/tvgate:v3.3.0（或 ghcr.io/qist/tvgate:v3.3.0）
- Android 端：配套 App v3.3.0（内嵌同版本服务端），App 内"在线更新"可直接升级

### 发布校验
- 每个 zip 均附 .dgst（MD5/SHA1/SHA256/SHA512），下载后可比对
- 二进制内嵌版本号：./TVGate-linux-64 -version → v3.3.0
- 完整 CHANGELOG（含 Android 段落）：doc/CHANGELOG.md
```
