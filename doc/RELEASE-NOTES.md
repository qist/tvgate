## 二、GitHub Releases 正文 · 精简版（用户可读）

```
### v3.3.0 更新内容
1. 修复部分直播源打不开 — 移动魔百盒等来源的频道以前一直转圈加载，现在能正常播放；切台也不再卡顿、不再一卡一卡
2. 整点不再长时间卡住 — 每到整点有些频道会卡几十秒甚至没声音；现在自动跳过缺失的一小段继续播，声音也会自动恢复
3. 多音轨频道不再没声音 — 带多条声音的频道（如杜比 AC-3）以前可能无声或信息显示不对，现在正常出声、显示正确
4. 广播频道能听了 — 只有声音的广播频道以前黑屏无声，现在可以正常收听，并显示广播画面
5. 节目单更准 — 多个节目单来源自动合并，主来源失效会自动换备用来源
6. 多线路频道可切换 — 同一频道有多个线路时可手动切换；当前线路坏了会自动换线路，不用重开
7. 频道列表焕新 — 首字台标、直播中标识、分组频道数量、搜索序号；播放页显示清晰度/帧率/编码等信息
8. 更省流量、起播更顺 — 打开频道少一次加载往返，播放过程按需取流；缓冲不足时自动补片更积极
9. 更稳定 — 服务重启时不再弹错误提示；播放进程异常会自动恢复，不用手动重开
10. 播放内核完成自研重构 — 使用方式、配置文件完全不变，为后续优化打好基础

升级：下载对应平台压缩包，解压覆盖后重启服务即可；Docker 用户重新拉取镜像。旧配置文件可直接使用，无需修改。
```

## 三、完整版（用于发布公告 / 论坛 / 通知，用户可读）

```
## TVGate v3.3.0（2026-09-19）

本次更新修好了几类"看不了、听着不对"的问题，并把频道列表和播放页做了焕新。

### 一、以前打不开的频道，现在能看了
- 移动魔百盒等来源的频道此前会一直转圈加载：这类源在节目切换点插入的关键数据不带
  时间戳，播放器识别不了就丢弃了，导致画面起不来；现在能正确识别并正常播放
- 同类问题的其他来源（如广场舞等）一起受益；顺带修好了"切台后一卡一卡、越看越卡"

### 二、整点不再长时间卡住
- 每到整点前后，部分频道的分片会短暂缺失，以前会卡几十秒；现在会自动跳过缺失的
  一小段继续播放
- 卡顿恢复后"只有画面、没有声音"的问题一并修复

### 三、声音相关的修复
- 带多条声音的频道（如杜比 AC-3 主音轨）以前可能没声音、或界面显示的音轨信息不对，
  现在正常
- 只有声音的广播频道：以前黑屏无声，现在可以正常收听，并显示广播画面
- 多线路/切台场景下的"声音与画面不同步"优化

### 四、更好用的地方
- 节目单（EPG）：多个来源自动合并，主来源失效时会自动换备用来源
- 多线路：同一个频道有多个线路时，可以手动切换；当前线路坏了会自动换到别的线路，
  不用自己重开
- 频道列表：增加首字台标、直播中标识、分组频道数量、搜索序号，更好看好找
- 播放页：清晰度 / 帧率 / 编码等信息展示更清楚
- 起播更快、更省流量；缓冲不足时自动补片更积极，临界缓冲更稳

### 五、更稳定
- 服务重启的瞬间不再弹出错误提示，重启后自动恢复
- 播放进程异常时会自动恢复，不用手动重开

### 六、关于播放内核
- 播放内核完成自研重构（合规处理），使用方式、配置项完全不变，为后续优化打好基础

### 兼容性与升级
- 配置文件向后兼容：旧 config.yaml 可直接使用，无需改动
- 二进制：下载对应平台压缩包，解压覆盖后重启服务（systemd：systemctl restart tvgate）
- Docker：docker pull juestnow/tvgate:v3.3.0（或 ghcr.io/qist/tvgate:v3.3.0），重建容器
- Android：安装 v3.3.0 版 APK 覆盖即可（App 内也支持在线更新）

### 发布校验
- 每个压缩包附 .dgst 校验文件（MD5/SHA1/SHA256/SHA512），下载后可比对
- 版本核对：./TVGate-linux-64 -version → v3.3.0
- 完整改动清单：doc/CHANGELOG.md（含 Android 段落）
```
