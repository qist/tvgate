```
### v3.4.1 更新内容
1. 修复 HLS 线路切到 MP4 线路后画面定格 — 播放器换用原生后端时，旧 H5（MSE）渲染画布
   仍保留着上一帧 HLS 画面并盖在真正播放的 <video> 之上；现换后端时同步撤掉该画面，

   matchMedia 缺失或被禁用不再中断首帧渲染；静态资源加载失败直接上屏提示，便于排障
6. 后台可用性 — 鉴权状态请求加 12 秒超时与「重试」入口，后端不可达时不再无限「加载中…」
7. 依赖更新 — golang.org/x/net 0.61.0、golang.org/x/text 0.43.0、gortsplib/v5 5.6.7
```

## 三、完整版（用于发布公告 / 论坛 / 通知，用户可读）

```
## TVGate v3.4.1（2026-10-18）

本次重点：修复「HLS 线路切到 MP4 线路后画面定格、必须刷新」这个长期存在的观感问题，
并给上游加了失败熔断，避免一条坏分片让服务端持续穿透上游、日志被刷满。

### 一、HLS → MP4 切换后画面定格（本次核心修复）

现象：某频道同时有多条线路，从 HLS 线路切到 MP4 线路后，画面停在切走前那一帧，
声音/时间在走但画面不动，只有刷新页面才能恢复；而另一条从起播就是 MP4 的频道一切正常。

根因：播放器有两套后端——H5（MSE 转封装 + WebGL 呈现）与原生 `<video>`。渐进式 MP4
必须走原生。切到 MP4 时播放器把旧的 MSE 实例销毁并新建原生实例，但**只清了实例引用，
没有复位该槽位的画面渲染状态**。于是旧的 WebGL 画布一直保持可见，上面是切走前最后一帧
HLS 画面，正好盖在下面已经正常播放的原生 `<video>` 之上。观感就是"画面定格"。

修复：换后端类型时同步复位渲染状态，旧画布立即隐藏。刷新能恢复，是因为刷新时槽位从
空状态起算——这也反向印证了上面的判断。

### 二、换线路不再串后端

- 换频道/换线路时同时作废上一台的首段容器探测结论。此前只清「强制原生」标记，
  上一台探成 MP4 的结论会留给下一台，把 TS/HLS 流也锁在原生后端，MSE 链路白丢
  （徽标、软解、追边全部失效）。
- 探测结果现在只允许把后端"抬"成原生，不再反过来覆盖设备能力判定。小米 UC（X5）等
  内核的 `MediaSource.isTypeSupported` 探测不过、本应走原生，若被探测结果改写成 MSE，
  整条播放链路会静默不启动（黑屏、点了没反应）。

### 三、上游失败熔断

- 同一「频道 + 上游地址」连续失败达到阈值后进入冷却期；冷却期内直接返回 502 并带
  `Retry-After`，不打上游、不打日志。
- 解析型源（会重跑 302 解析链）连败 3 次熔断 30 秒；分片/解析后地址一次性失效居多，
  首次失败即熔断 30 秒——前端刷新播放列表就会换到新 token，不会因此被长期挡住。
- 冷却时长每再触发一次就翻倍，上限 5 分钟；任何一次成功立即清零，恢复时靠半开探测放行。
- 冷却必须长于客户端重拉节奏（播放器按播放列表 targetDuration 轮询，实测约 14 秒），
  否则每次重拉刚好落在冷却之外，熔断形同虚设。

### 四、m3u8 改写归一

- 列表改写后统一按 200 全量返回，不再保留 206 语义。
- EXT-X-KEY / EXT-X-MAP / EXT-X-MEDIA 内嵌 URI 统一走代理与域名映射，不再直连源站。
- 路径单斜杠收紧；TS 分片恢复定长输出。

### 五、老内核播放页兼容

- 不支持 module worker 的内核（X5/U4、Chrome < 80）自动退到 classic worker，
  MSE 链路不再因 worker 创建失败而整体瘫痪（此前表现为黑屏且无任何错误）。
- localStorage 被禁用 / matchMedia 缺失时不再中断首帧渲染与主题初始化。
- 静态资源加载失败（旧 HTML 引用了已删除的 hash 资源）直接上屏提示，这是
  「标题正常、页面全白」最常见的原因，现在能一眼看出。

### 六、后台可用性

- 鉴权状态请求加 12 秒超时，失败时给出「无法连接服务器」与「重试」按钮，
  不再无限停在「加载中…」。

### 兼容性与升级

- 配置文件向后兼容：旧 config.yaml 可直接使用，无需改动
- 二进制：下载对应平台压缩包，解压覆盖后重启服务（systemd：systemctl restart tvgate）
- Docker：docker pull juestnow/tvgate:v3.4.1（或 ghcr.io/qist/tvgate:v3.4.1），重建容器
- Android：安装 v3.4.1 版 APK 覆盖即可（App 内也支持在线更新）

### 发布校验

- 每个压缩包附 .dgst 校验文件（MD5/SHA1/SHA256/SHA512），下载后可比对
- 版本核对：./TVGate-linux-64 -version → v3.4.1
- 完整改动清单：doc/CHANGELOG.md（含 Android 段落）
```
