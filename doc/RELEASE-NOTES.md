```
### v3.3.8 更新内容
1. 组播（IPTV 组播源）高码率/4K 花屏、蓝屏根因修复 — 下发给播放器的数据块此前会
   引用被下一个网络包复用的内存，导致同一段画面数据被重复发送，4K 高码率下尤为
   明显（周期性花屏甚至蓝屏）；现改为按实际长度发送独立副本，现象消失
2. 4K 组播卡顿改善 — 下发路径回归「每包即时直写、不再攒批」，出图更及时、
   缓冲更小，高码率下的延迟与卡顿明显减少；另加大 RTP 去重窗口、TS 连续性补齐
   对齐旧版行为，弱网/乱序下更少误判与丢帧
3. 组播长时间运行稳定性 — 修复客户端加入/移除竞态导致的内部对象泄漏（反复换台、
   多客户端进出后不再残留内存与 UDP socket），长时间运行更稳
4. 旧版组播网卡配置自动迁移 — 沿用旧版配置（server.multicast_ifaces）未改字段的
   用户，升级后不再出现部分组播频道 0 字节/绿屏，无需手工改配置
5. 订阅内联代理与请求头（新增） — 订阅文件里可直接为频道指定上游代理与
   Referer/Origin（proxy= / referer= / origin=，支持组级与频道级），无需先在
   后台建代理组规则；支持 socks5 / socks4 / http(s)，多个代理自动挑选最快，
   302 跳转与后续分片全程走同一出口，直播、回看、点播一致生效
6. 播放页无感换台回归修复 — 换台过渡期旧频道画面+声音继续播放，直到新频道真正
   接上的那一刻才切换（此前「点一下换台就停播、等下一个节目起播」）；换流遮罩
   只在硬切/无缝失败回退时出现；播放页控制条恢复整幅铺满

升级：下载对应平台压缩包，解压覆盖后重启服务即可；Docker 用户重新拉取镜像；
安卓盒子/电视直接覆盖安装新版 APK（App 内也支持在线更新）。旧配置文件可直接使用，无需修改。
```

## 三、完整版（用于发布公告 / 论坛 / 通知，用户可读）

```
## TVGate v3.3.8（2026-10-03）

本次重点修复组播（IPTV 组播源）在 4K/高码率下的花屏、蓝屏与卡顿问题，
并新增「订阅内联代理」，同时修复播放页无感换台的观感回归。

### 一、组播花屏/蓝屏根因修复（4K 高码率最明显）

- 现象：4K 等组播频道周期性花屏，严重时整屏蓝屏；普通高清频道不易复现
- 根因：下发给播放器的 TS 数据块此前直接引用一块会被后续网络包复用的缓冲区，
  下一个包到达时会就地覆盖这块内存，于是同一段画面数据被重复下发
  （实测远端视频 PID 出现连续 8 次逐字节完全相同的 7 包块）
- 修复：读入与下发都改为按实际长度的独立副本，彻底消除缓冲别名；另补回归测试

### 二、组播卡顿与稳定性改善

- 下发路径回归「每包即时直写」，不再攒批：出图更及时、单次下发更小，
  4K 高码率下的延迟/卡顿明显减少（保留 50ms 兜底刷新与慢客户端丢包诊断日志）
- RTP 去重窗口由 64 加大到 200 并全量比对（去掉「只看最近 8 个」的截断），
  弱网/乱序场景下更少误判重复包
- TS 空包（nullTS）补齐字节与连续性处理对齐旧版行为，CC 缺口按差量补 null
- 修复客户端加入/移除竞态导致的内部对象泄漏：反复换台、多客户端进出后，
  不再残留客户端条目与 UDP socket（此前会导致长时间运行后内存与句柄增长）
- 组播响应 Content-Type 恢复为 video/mpeg，兼容旧播放器与 4K 解码路径

### 三、旧版组播网卡配置自动迁移

- 旧版配置里的 server.multicast_ifaces 已迁移到 multicast.multicast_ifaces
- 沿用旧配置、未改字段的用户升级后，组播网卡列表不再丢失，
  避免部分组播频道（新频道/新 VLAN）收不到、表现为 0 字节/绿屏

### 四、订阅内联代理与请求头（新增）

- 订阅（TXT）新增 proxy= / referer= / origin= 行，与 ua= 并列，支持组/文件级
  默认与频道级覆盖；M3U 订阅支持同名的 EXTINF 属性
- 可为频道直接指定上游代理，无需先在后台建代理组规则；多个代理用逗号分隔，
  服务端按 fastest 自动挑选最快（与代理组的负载均衡同一套测速逻辑）
- 支持 socks5 / socks4 / socks4a / http / https，可带 user:pass@ 认证，
  省略 scheme 默认 http://
- 302 重定向由服务端经同一代理跟随（最多 10 跳），重定向目标、子清单与
  TS 分片全程同一出口；显式 referer= / origin= 跳转后保留，自动 Referer 剥离
- 未配置即忽略，回落原有域名规则代理组 / 直连；直播、回看、点播共用同一链路

### 五、播放页无感换台回归修复

- 换台过渡期不再提前中断旧频道：旧频道画面+声音照常播放，新频道在后台静默起播，
  真正接上的那一刻画面与声音一起切换（修复「点一下换台就停止播放、
  等下一个节目起播」的观感回归）
- 换流遮罩只在硬切/无缝失败回退时出现，无缝路径不再上遮罩
- 播放页控制条恢复整幅铺满，展开侧栏时由侧栏盖在其上从后面穿过

### 兼容性与升级
- 配置文件向后兼容：旧 config.yaml 可直接使用，无需改动
- 二进制：下载对应平台压缩包，解压覆盖后重启服务（systemd：systemctl restart tvgate）
- Docker：docker pull juestnow/tvgate:v3.3.8（或 ghcr.io/qist/tvgate:v3.3.8），重建容器
- Android：安装 v3.3.8 版 APK 覆盖即可（App 内也支持在线更新）

### 发布校验
- 每个压缩包附 .dgst 校验文件（MD5/SHA1/SHA256/SHA512），下载后可比对
- 版本核对：./TVGate-linux-64 -version → v3.3.8
- 完整改动清单：doc/CHANGELOG.md（含 Android 段落）
```
