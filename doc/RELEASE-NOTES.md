## 二、GitHub Releases 正文 · 精简版（用户可读）

```
### v3.3.1 更新内容
1. 断线自动续播 — 直播源定时断开连接时，以前会出现"重连了但画面不动"，或者延迟越拖越长；
   现在会自动接上时间轴继续播，延迟保持在几秒内
2. 换线路更可靠 — 解析出的播放地址会定期刷新，失效就立刻重新解析，不再一直重连同一条坏地址
3. 开启缓存后新观众不再黑屏 — 打开 TS 缓存（多人共享一路流）时，后加入的观众拿不到编码参数
   会黑屏或花屏，已修复
4. 手机端控制条移到画面外 — 播放/音量/换线路放到画面下方，被浏览器"接管画面"的机型
   （如小米浏览器）也能正常看到和点击；换线路改为点击弹出的置顶菜单，选完自动收起
5. 修复"切台后画面全黑、点一下才恢复"，以及小米等浏览器"没有媒体徽标 / 部分台黑屏"
6. 起播更快 — 不再为判断播放列表白等几秒，FLV 直播起播更快、也少拉一路数据
7. 新增播放诊断浮层 — 播放地址加 ?dbg=1 打开，报障时可一眼看清播放状态

升级：下载对应平台压缩包，解压覆盖后重启服务即可；Docker 用户重新拉取镜像。旧配置文件可直接使用，无需修改。
```

## 三、完整版（用于发布公告 / 论坛 / 通知，用户可读）

```
## TVGate v3.3.1（2026-09-19）

本次更新集中解决两件事：直播看着看着"停住不动"，以及手机端不好操作。

### 一、直播停住会自己接上了
- 直播来源（尤其第三方 CDN）会定时断开连接。以前断开重连后，画面会停在断开的那一刻不动，
  或者直播延迟越拖越长；现在重连会自动接续时间轴继续播，延迟保持在几秒以内
- 换线路、换源之后同样直接续播，不用手动重开

### 二、换线路更可靠
- 以前解析出来的播放地址会被一直复用，地址过期后就表现为"播几秒断一次、不停重连"；
  现在地址会定期刷新，并且一旦发现失效就立刻重新解析

### 三、开启缓存后，后加入的观众不再黑屏
- 打开 TS 缓存（多个观众共享一条上游）时，后加入的观众拿不到编码参数（SPS/PPS、AAC 配置），
  会黑屏或花屏；现在头信息按完整数据包解析并正确下发

### 四、手机端更好用
- 原生播放时，播放/暂停、音量、换线路移到画面下方——被浏览器接管画面的机型（如小米浏览器）
  也能正常看到和点击
- 换线路改为点击弹出、置顶显示的菜单，选中后自动收起

### 五、修复与优化
- 切台后画面全黑、需要点一下才恢复
- 小米等浏览器"没有媒体徽标 / 部分台黑屏"
- 起播更快：不再为判断播放列表白等几秒，起播少拉一路数据
- 新增 ?dbg=1 播放诊断浮层（报障时使用）

### 兼容性与升级
- 配置文件向后兼容：旧 config.yaml 可直接使用，无需改动
- 二进制：下载对应平台压缩包，解压覆盖后重启服务（systemd：systemctl restart tvgate）
- Docker：docker pull juestnow/tvgate:v3.3.1（或 ghcr.io/qist/tvgate:v3.3.1），重建容器
- Android：安装 v3.3.1 版 APK 覆盖即可（App 内也支持在线更新）

### 发布校验
- 每个压缩包附 .dgst 校验文件（MD5/SHA1/SHA256/SHA512），下载后可比对
- 版本核对：./TVGate-linux-64 -version → v3.3.1
- 完整改动清单：doc/CHANGELOG.md（含 Android 段落）
```
