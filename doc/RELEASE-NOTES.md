## 三、完整版（用于发布公告 / 论坛 / 通知，用户可读）

```
## TVGate v3.3.5（2026-09-26）

本次更新集中修复管理后台在手机上的显示问题：多处页面横向溢出、按钮被裁出
屏幕，编辑内容类页面尤其明显；另修掉任务页一个必现的页面崩溃。

### 一、管理后台手机端排版修复
- 页头按钮行此前不换行：YAML 编辑器「保存」、配置备份「批量删除」、备份中心、
  域名映射的按钮在窄屏被裁到屏幕外；现改为可换行，窄屏自动分行且仍靠右
- 列表页（配置备份 / 备份中心）行内操作按钮此前占满宽度，把文件名挤成
  「config.yaml…」看不出是哪个备份；现窄屏操作区独立成行右对齐，文件名拿回
  整行宽度（实测列宽 78px → 256px）
- 文件列表行操作按钮：移动端常显（无悬停可用），桌面端仍保持悬停显示

### 二、配置内容编辑器工具栏
- 「编辑文件」页工具栏此前被锁定在 627px 宽，使换行失效、整页可横向滚动
  （实测内容宽 652px 而屏宽 390px），末尾「检测/批量替换/下载/关闭」全被裁；
  现窄屏分两行（文件名一行、按钮组一行），大屏恢复同行

### 三、卡片横向溢出根因
- 全局卡片组件补 min-w-0：卡片作为弹性/网格子项时默认不收缩，会被内部宽表格
  或代码块撑开，导致整页横滑、内部滚动条同时失效

### 四、任务页崩溃修复
- 点「添加」新增任务时页面报 Cannot read properties of undefined
  (reading 'cron')：越界读取尚未生成的任务项，现改为直接进入编辑态

### 五、升级体验
- 后台入口 HTML 缓存策略由 no-cache 改 no-store：升级后设备上不会再拿着
  旧页面引用已不存在的旧资源（此前表现为「改了但界面上还是旧的」）

### 兼容性与升级
- 配置文件向后兼容：旧 config.yaml 可直接使用，无需改动
- 二进制：下载对应平台压缩包，解压覆盖后重启服务（systemd：systemctl restart tvgate）
- Docker：docker pull juestnow/tvgate:v3.3.5（或 ghcr.io/qist/tvgate:v3.3.5），重建容器
- Android：安装 v3.3.5 版 APK 覆盖即可（App 内也支持在线更新）

### 发布校验
- 每个压缩包附 .dgst 校验文件（MD5/SHA1/SHA256/SHA512），下载后可比对
- 版本核对：./TVGate-linux-64 -version → v3.3.5
- 完整改动清单：doc/CHANGELOG.md（含 Android 段落）
```
