## 三、完整版（用于发布公告 / 论坛 / 通知，用户可读）

```
## TVGate v3.3.3（2026-09-24）

本次更新集中解决苹果设备上的三类播放问题：iPhone 转圈、iOS 15 白屏、失败原因不明，
并把播放器的诊断日志整理成按需开关。

### 一、iPhone Safari 播放一直转圈修复
- iOS 17+ 的 Safari 使用系统托管的媒体源（ManagedMediaSource），其激活条件要求在
  挂载视频源之前、于 video 元素上声明"本页面不使用投屏"；此前这一声明被误设到
  无效的位置，系统投屏预期抑制了画面就绪事件，播放管线永远不启动，表现为一直转圈
- 已按规范把声明设置到位；同时播放管线改为就绪即启动、首包数据暂存补发，
  不再被事件时序"饿死"；就绪看门狗一并修复（重载场景不再静默卡住）
- 播放诊断浮层新增媒体源状态行（MS源），报障时一眼确认系统托管源是否激活

### 二、iOS 15 打开播放页白屏修复
- iPhone Safari 16.4 之前没有屏幕方向接口，页面直接解构该接口导致脚本崩溃、
  React 整树无法挂载，表现为打开播放页整页白屏
- 已改为接口存在性判断 + 视口宽高降级判断横竖屏（监听注册/清理同样守卫）

### 三、播放失败提示更明确（原生播放路径）
- 播放失败时上报浏览器媒体错误的具体代码与信息（此前只有一句"播放失败"无细节）
- 换台触发的良性加载中断不再当失败上报，避免误触错误恢复、来回切线路
- 解码/格式类失败追加明确提示：常见于 MP2/MP3/AC-3 音轨源不被系统原生播放支持
  （iOS 15 无媒体源扩展只能走原生路径；安卓与 iOS 17+ 引擎路径有软解可正常观看），
  属设备系统级限制

### 四、启动错误上屏
- 两个入口页面的引导脚本加入错误捕获：脚本异常、资源加载失败直接在页面底部
  红条显示，白屏 6 秒兜底提示——旧 WebView / 低版本系统上"白屏无声无息"不再
  （本次 iOS 15 的崩溃正是靠它一眼定位）

### 五、播放器诊断日志收口
- 全部诊断性控制台日志统一收口到调试开关：默认关闭、控制台零输出
- 三种开启方式：播放地址加 ?dbg=1；控制台执行 __tvdbg()；或
  localStorage['tvgate-player-debug']='1' 后刷新——主线程与解码工作线程全覆盖
- 真正的错误日志（播放失败、启动崩溃等）不受开关影响，始终显示

### 兼容性与升级
- 配置文件向后兼容：旧 config.yaml 可直接使用，无需改动
- 二进制：下载对应平台压缩包，解压覆盖后重启服务（systemd：systemctl restart tvgate）
- Docker：docker pull juestnow/tvgate:v3.3.3（或 ghcr.io/qist/tvgate:v3.3.3），重建容器
- Android：安装 v3.3.3 版 APK 覆盖即可（App 内也支持在线更新）

### 发布校验
- 每个压缩包附 .dgst 校验文件（MD5/SHA1/SHA256/SHA512），下载后可比对
- 版本核对：./TVGate-linux-64 -version → v3.3.3
- 完整改动清单：doc/CHANGELOG.md（含 Android 段落）
```
