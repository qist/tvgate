## 三、完整版（用于发布公告 / 论坛 / 通知，用户可读）

```
## TVGate v3.3.4（2026-09-25）

本次更新集中解决三类"改了配置但不生效/数据不准"的问题：代理组规则残留、
EPG 错配与滞后、台标死链反复探测拖慢启动，并给代理组加了一键清缓存入口。

### 一、代理组「改规则仍走旧规则」修复
- 根因：域名分流映射的访问缓存此前按"新配置里的域名列表"与旧缓存条目求交集
  决定是否清理——组内域名删光或整批挪到别的组时交集为空，旧映射残留，请求
  继续走改前规则；整组删除/改名则完全没有清理动作
- 现在：配置变更按组名全量清理该组全部缓存条目；整组删除/改名也会补清，
  改完规则下一个请求即按新规则分流

### 二、每组「清理缓存」按钮
- 管理后台代理组页面，每组新增一键清理：立即清空该组全部访问缓存并重置
  测速统计（存活状态/响应时间/失败计数/冷却期归零），下次请求强制重新测速
  选节点——不放心自动清理时随时手动兜底

### 三、EPG 每日 0 点强制过期
- 节目单缓存每天凌晨 0 点自动失效并重拉（跨天旧节目单不再残留）
- 订阅周期刷新行为不变；模板类 EPG 仍是查询时实时拉取

### 四、EPG 频道错配修复
- 带画质后缀的频道名（如 CCTV1-4K、北京卫视4K）此前原样发给外源 EPG 服务，
  被模糊匹配到无关频道——实测 CCTV1-4K 拿到的是 CCTV14 少儿频道的节目单
- 现在查询前先剥画质后缀（CCTV1-4K→CCTV1、北京卫视4K→北京卫视），剥完
  无结果再回落原始名；紧跟数字/字母的名字不受影响（如 CCTV4K→CCTV4 不会
  误剥成 CCTV）

### 五、启动更快、台标不再闪 404
- 台标死链探测移出启动/重载关键路径：频道列表不再等探测完成，APK/服务
  打开更快；探测在后台限量并发执行（30 秒预算），完成后落盘
- 探测结论持久化到配置目录（logo_probe.json），进程重启不再重复探测，
  死台标不随重启"复活"闪 404

### 六、稳定性
- 修复配置热更新发布路径一处长期存在的数据竞争（-race 检出）
- 依赖更新：gortsplib/v5 5.6.5 → 5.6.6

### 兼容性与升级
- 配置文件向后兼容：旧 config.yaml 可直接使用，无需改动
- 二进制：下载对应平台压缩包，解压覆盖后重启服务（systemd：systemctl restart tvgate）
- Docker：docker pull juestnow/tvgate:v3.3.4（或 ghcr.io/qist/tvgate:v3.3.4），重建容器
- Android：安装 v3.3.4 版 APK 覆盖即可（App 内也支持在线更新）

### 发布校验
- 每个压缩包附 .dgst 校验文件（MD5/SHA1/SHA256/SHA512），下载后可比对
- 版本核对：./TVGate-linux-64 -version → v3.3.4
- 完整改动清单：doc/CHANGELOG.md（含 Android 段落）
```
